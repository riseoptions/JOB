# Neljanda etapi tulemused

Valmis eestikeelne veebirakendus viie põhivaatega. Varasemad Python-ärireeglid on säilitatud; lisatud on adapter, staatiline veebiehitus ja brauseri Python Worker. 51 Python-testi läbivad ning põhiline import/eksport ja finantsfiltrid on kontrollitud päris brauseris.

## Tarnitav tulemus

- Interaktiivne eelarve- ja kuluvaade, asutuse/perioodi valik, graafik ning selge metoodika.
- Ostuarvete otsing, sortimine, duplikaadid, veapõhjused, CSV/XLSX import ning valitud või kogu seansi eksport.
- Pythoni loodud Exceli koond, CSV-d, SQLite ja projektifailide ZIP.
- Uuendatud arhitektuur, andmemudel, spetsifikatsioonid ja juhendid.
- Neljanda etapi 30-minutiline õppemoodul viie lahendatud harjutusega.
- GitHub Pagesi staatiline avaldamisvalmidus ja Actionsi töövoog.

## Olulised piirid

Arved ja toetused on sünteetilised; veeb ei tee kinnitusi ega makseid. Arveseanss on ainult jooksva brauserikaardi mälus. Avalikud finantsandmed on etappides 1–3 hangitud kindla perioodi väljavõtted, mitte reaalajaandmed. Aastaeelarve jääki ei nimetata perioodi säästuks. GitHub Pages ei käita serveripoolset Pythonit.

**Etapp 5 on alustamata.** Üldine lõppaudit, terviklik koondkursus ning kandideerimiseks mõeldud esitluspakett jäävad järgmisse etappi. Selles tarnes tehtud testid ja õppematerjal on neljanda etapi töö vajalik osa.
